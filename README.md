# Daily Code Tracker

A lightweight, responsive web application to track daily coding practice with a GitHub-style contribution heatmap.

## Features

- GitHub-style activity heatmap for the last 365 days
- Total questions solved
- Current streak and best streak
- Active practice days
- Log questions by topic
- Record time spent and learning notes
- Save optional GitHub or coding-platform links
- Edit and delete practice entries
- Export and import JSON backups
- Responsive layout for desktop and mobile
- No framework, build process, or backend required

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Add a practice entry each day.

## Data Storage

Practice records are stored in the browser's localStorage. They are not automatically synchronized across browsers or devices. Export JSON backups regularly.

## Deployment

This project can be hosted using GitHub Pages.

1. Open the repository's Settings.
2. Select Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select the `main` branch and `/ (root)` folder.
5. Save the settings.

## Goal

Solve at least one coding question every day and build a consistent learning habit.
